For every case also check: correct endpoint; preservation of explicit boundaries and necessary capabilities; concrete outcome rather than topic labels; truthful source and verification claims; proportionate user burden.

Research may confirm an existing choice. A source count is not a quality score. An explicit source-read trace is stronger evidence than an answer merely naming a URL. If the host exposes only an agent's report, label that provenance and do not present it as an independently captured tool trace.

Treat lost required capabilities, explicit scope violations, and invented evidence as critical failures. Do not average them away. Keep absent observations unverified. A design judgment needs a reason tied to the task or artifact; it is not measured audience success.

Start with one paired run per case. Before broader effectiveness claims, repeat the high-value implementation, restraint, and research cases under equivalent conditions. Expand only to resolve concrete uncertainty. A successful synthetic sample is not a release-wide guarantee.
